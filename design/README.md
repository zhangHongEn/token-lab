# Token Lab · 工作台设计提案

可交互的高保真设计稿，入口为项目根目录的 `design.html`。主页面与流程编辑器使用现有 Vue、ECharts 与会话计算引擎。

## 打开预览

启动项目开发服务后，打开 `/design.html`。当前本地地址：

http://localhost:5174/design.html

独立构建：

```sh
npx vite build --config design/vite.config.js
```

构建结果位于被 Git 忽略的 `output/design-preview/`，入口为 `design.html`。此命令只生成本地预览文件，不会上传 CDN。

## 当前界面

- 首页恢复原有品牌头部、数字背景、全局配置卡片、暖色按钮及费用分析布局。
- 首页以紧凑对比表展示总费用、相对基准、命中率、初始上下文、峰值请求输入和模型请求次数。点击方案名或行首箭头可独立展开、收起详情。
- 展开后左侧保留原费用卡片，右侧展示初始上下文与每轮流程图，包括步骤顺序、启停状态、模型调用、实际 Token 长度与压缩条件；支持展开公式和切换预览轮次。
- 表格支持编辑、复制、删除及设为基准，与原全局配置和分析面板共享同一份实验数据。
- 方案编辑仍采用三栏工作区，基本参数、缓存与压缩、模型与费率分区和实时成本预览保持原设计。
- 原首页样式限定在 `.restored-home` 内，避免影响编辑页。

## 可体验范围

全局参数调整、方案新增 / 复制 / 删除、基准切换、撤销、配置导入导出；流程增删与排序、步骤启停、固定长度与公式、变量插入、模型预设、费用归因与请求记录。

金额与 Token 数值由现有模拟引擎计算，不是静态演示数字。价格为项目自带快照。配置仅保留在本次页面会话中，刷新前需导出。

## 验证记录

- 设计入口独立构建通过。
- Chrome「用户1」验证桌面页面与 390px 窄屏，无页面横向溢出。
- 将 Agent Prompt 公式由 `initialContext.agentPromptToken` 改为两倍：步骤预览由 4K 变为 8K，会话成本由 $77.79 变为 $82.00；保存更新对比，撤销恢复原结果。
- 未知公式变量会显示错误并阻止保存；取消可返回原方案。
- 压缩请求筛选得到 12 次请求，分页第二页显示剩余 4 条。
- 公式求值只允许确定性的数学函数；`Math.random()` 等非确定性函数会被拒绝。

2026-10-23 首页调整验证：独立构建通过；表格编辑可进入原三栏编辑页；切换基准正确更新差异百分比，撤销恢复原基准；浏览器未发现运行错误。

2026-10-23 展开流程验证：按需方案显示 4 个初始化步骤与 8 个每轮步骤，初始上下文合计 8.989K；全量方案显示 5 个初始化步骤与 6 个每轮步骤，合计 54.889K。公式展开、预览轮次切换正常，390px 窄屏无页面横向溢出。
